Vaultwarden is the self-hosted, Bitwarden-compatible password vault. It runs in the `vaultwarden` namespace and stores its data in the `vaultwarden` Postgres database on `db.internal`.

## Credentials

| Credential            | Where it lives                                                  | What it unlocks                    |
| --------------------- | --------------------------------------------------------------- | ---------------------------------- |
| Admin token           | `k8s/dev/vaultwarden/secrets/vaultwarden-admin-token.sops.yaml` | `/admin` only                      |
| Database password     | `k8s/dev/vaultwarden/secrets/vaultwarden-db-password.sops.yaml` | the `vaultwarden` Postgres role    |
| Tunnel token          | generated by `ansible/playbooks/cloudflare/tunnels.yaml`        | the `cloudflared` connector        |
| Vault master password | offline record held by you                                      | account login and vault encryption |

The first three are server credentials and live in the repository's sops stores. The master password is not a server credential. It must not be stored in the cluster or in the repository's sops store.

Retrieve the admin token with:

```bash
sops -d --extract '["stringData"]["admin-token"]' \
  k8s/dev/vaultwarden/secrets/vaultwarden-admin-token.sops.yaml
```

## First login

Vaultwarden starts with no accounts. Kubernetes and Ansible do not create one, and the server cannot create the master password.
You create the first account once, through the signup flow, and are responsible for safe-guarding the credential.

1. Open (the admin panel)[https://vaultwarden-dev.ericzhu.me/admin] and sign in with the admin token.
2. Under **Users**, create the account email. It should appear as **Invited**. No email will be sent since no SMTP is configured.
3. Open (the signup page)[https://vaultwarden-dev.ericzhu.me/#/signup] and use the exact invited email. Choose a strong master passphrase.
4. Sign in in a private window to verify the record.

The admin token is not a vault login. The admin panel can remove 2FA, deauthorize sessions, disable a user, and delete a user, but it cannot reveal the master password. Since SMTP is unconfigured it cannot deliver a reset email.
