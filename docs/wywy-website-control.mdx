## Wywy-Website-Control Repository

This repo contains cluster-wide provisioning artifacts, including manifests, scripts, configuration, and secrets.

Wywy-Website-Control has a handful of Bash scripts and mainly hinges on Ansible, SOPS, and ArgoCD.

## Entry points

| What                  | Command                                                            |
| --------------------- | ------------------------------------------------------------------ |
| Ansible toolchain     | `scripts/install/ansible.sh`                                       |
| Run a playbook        | `uv run --directory ansible wywy-ansible --dev\|--prod <playbook>` |
| Proxmox installer ISO | `scripts/install/preseeds/proxmox/build-proxmox-iso.sh`            |
| Cluster base          | `scripts/install/k8s/k8s-base.sh`                                  |
| Platform components   | `scripts/install/k8s/<component>.sh`                               |
