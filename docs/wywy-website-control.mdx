## Wywy-Website-Control Repository

This repo contains the provisioning, cluster manifests, CI images, configuration, and documentation for the entire website. It does not include blog content or database data. The services themselves live in their own repositories.

All commands run from `/etc/Wywy-Website-Control/`.

## Entry points

| What                  | Command                                                                                            |
| --------------------- | -------------------------------------------------------------------------------------------------- |
| Ansible toolchain     | `scripts/install/ansible.sh`                                                                       |
| Run a playbook        | `uv run --directory ansible wywy-ansible --dev\|--prod <playbook>`                                 |
| Proxmox installer ISO | `scripts/install/preseeds/proxmox/build-proxmox-iso.sh`                                            |
| Cluster base          | `scripts/install/k8s/k8s-base.sh`                                                                  |
| Platform components   | `scripts/install/k8s/<component>.sh` — `prometheus-stack`, `linkerd`, `keda`, `longhorn`, `argocd` |
| CI runner images      | `scripts/install/github-runner/build.sh`, `scripts/install/github-runner/push-image.sh`            |
| Deploy runners        | `scripts/install/k8s/github-runners.sh`                                                            |
| Deployment tests      | `bats tests/`                                                                                      |

## Notes

- Installation is layered. `ansible/playbooks/` owns VM creation and service configuration.
- Argo CD reconciles the Kubernetes manifests from `k8s/dev/infrastructure/app-of-apps.yaml`.
