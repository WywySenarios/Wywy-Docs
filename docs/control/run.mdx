---
title: Running Docker Containers
published: 2026-03-30T20:46:58+00:00
---

A general (wrapper) script for running docker containers is located at `/etc/Wywy-Website-Control/run.sh`. This will call docker compose up (build if not already built and run) on the specified project. Additional flags can be added at the end.
The usage for the general script is: `/etc/Wywy-Website-Control/run.sh \[service name\] ...\[flags\]`

Example usage:
`/etc/Wywy-Website-Control/run.sh website prod --build`

Scripts for specific services can be found under directory `/etc/Wywy-Website-Control/scripts/run`. The exec target will only be consumed if the docker compose command is "exec". Each service may have aliases for its docker services.
The usage for these sub-scripts is: `/etc/Wywy-Website-Control/scripts/run\[service name\].sh \[docker compose command \(e.g. up\)\] \[development environment \(e.g. prod\)\] \[exec target\] ...\[flags\]`

Example usage:
`/etc/Wywy-Website-Control/scripts/run/website.sh up prod`
`/etc/Wywy-Website-Control/scripts/run/website.sh up prod website --build`

NOTE: The backup script is empty because the backup server does not have any docker services.
