---
title: Entering Docker Containers
published: 2026-03-30T21:06:55+00:00
---

A general (wrapper) script for entering docker containers is located at `/etc/Wywy-Website-Control/enter.sh`.

Usage: `/etc/Wywy-Website-Control/enter.sh \[service name\] \[docker service name or alias\] \[development environment\]`.

Example usage:
`/etc/Wywy-Website-Control/enter.sh master-database pgres prod`
