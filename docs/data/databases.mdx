## Sub Columns

Sometimes the attributes of a piece of data cannot be represneted by a single Postgres column. In this case, one or more subcolumns will be created to represent the additional data. These subcolumns count towards the maximum column count for a table.

## Pointer

A pointer is a datatype that refers to an entry of another table within the same database. A pointer may only refer to one other type of table at a time.

It is implemented as a foreign key dependency to the ID column of another table. The implementation theoretically allows for some entries to be permanently stuck inside the cache to sync, but this is OK since the cache is meant to be periodically cleaned.

## Polymorphic Pointer

A polymorphic pointer is a datatype that refers to any entry from another table within the same database.

It is implemented as an INTEGER and a TEXT subcolumn representing the related table name. The current implementation does not guarentee the validity of the polymorphic relationship.

Polymorphic pointers cannot point to tag_aliases subtables.

Aliases of this datatype name include:

- polymorphic pointer
- polypointer
