# Serialization (Out-bound Data)

Data should be serialized to valid JSON.

## Complete vs. Incomplete Data

Complete data objects contain every required column and sub-column for the respective table.

Incomplete data objects do not need every required and sub-column for the respective table.

No erroneous columns or sub-columns should ever be passed in. Any server that receives an erroneous column should respond with an error (e.g. HTTP 400).

## Entries

A table entry is an entry whose schema relates to a table.

A descriptor entry is an entry whose schema relates to a descriptor.

## Full Entries

A full entry contains:

- `data`
- `tags` if tagging is enabled
- `descriptors` if the respective table has descriptors

The tags supplied should be an array of numbers (i.e. tag_id). This array may be empty.

The descriptors should be supplied in a JSON object with keys.

## Potential Server-side Restrictions

The maximum size of an INSERT query (i.e. after deserialization) is 65536 bytes. This maximum is not necessarily enforced everywhere.
