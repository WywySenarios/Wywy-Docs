## Purpose

Runs Python integration tests against a running sql-receptionist (test mode only).

## Dockerfile

`apps/tests/Dockerfile` — `python:3.12-slim`, installs test deps. Command: `python3 -m unittest discover -s /home/wywy -t /home/wywy`.

## Docker Compose

Test-only in `docker-compose.test.yml`. Depends on `postgres` (healthy) + `sql_receptionist` (started). Mounts `apps/tests` as source.
